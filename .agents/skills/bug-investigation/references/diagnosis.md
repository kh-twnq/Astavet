# Diagnosis packet

Record expected/observed behavior, environment/toolchain, repeatable trigger,
probe command, result, hypothesis supported/rejected, owner and root-cause path.
A failing test on the clean base distinguishes pre-existing failures; use an
isolated worktree when available instead of stash/pop in the user's dirty tree.
After two different failed approaches reconsider the causal model. Ask the
engineering-advisor only for a material unresolved decision. No production writes.
