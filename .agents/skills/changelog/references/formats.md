# Changelog formats

Preserve existing heading level, section order and reference/inline links.
Keep a Changelog commonly uses Added, Changed, Deprecated, Removed, Fixed,
Security. Conventional feat maps to Added; fix to Fixed; perf/refactor to Changed;
dependency changes are Security only with verified security relevance. Detect
SemVer, two-component, CalVer or custom versions from explicit config/tags.
Suggest a bump from actual compatibility and range; do not create the tag.
