# Review thread workflow

GitLab discussions and GitHub review threads have different IDs and permissions.
Use live configured tools and read all pagination, replies and resolvability.
Questions may need an answer; code requests need a verified change; optional
suggestions may be declined; disagreements stay open for the reviewer.
Draft replies with the actual pushed commit, publish only when authorized, then
resolve only addressed concerns. Do not blindly close every thread or infer
publication authorization from a local fix request.
