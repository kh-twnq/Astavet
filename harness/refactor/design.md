# Codex adaptation

Native AGENTS.md/config/hooks/agents replace Claude instructions/settings/model
frontmatter. Skills expose all original capabilities plus lifecycle entrypoints.
References preserve detailed teaching. This harness retains the source team policy, including approval, no comments, frontend unit-test-writing exception and Jira planning conventions; see [adaptation contract](../references/codex-adaptation.md).

Deterministic ledger and graph use one task state with optional graph metadata.
Graph results assert evidence; test/review nodes are checked against actual current
ledger reports. Ready checks dependencies and snapshot freshness before commit.
Workspace aggregation verifies independent repos and reports contract evidence;
it does not pretend to run a root monorepo build or auto-prove HTTP compatibility.
External mutations retain explicit user authorization boundaries.
