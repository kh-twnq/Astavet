# Migration checklist

Install at each Git root, configure actual commands and project identity. Read [adaptation contract](../references/codex-adaptation.md); confirm retained team policy and do not silently replace it with generic Codex defaults. Fill
AGENTS.md repo map and workspace.repos. Validate doctor, skills and hook payloads
in a new trusted local session. Use start/graph init, then scope/plan/implement,
verify/review/security/integrate as routed, ready and authorized publication.
Run a bug, feature, docs task, MR review/feedback, conflict resolution, handoff,
and release audit pilot. Record integration availability instead of fabricating
remote test success. Archive prompts stay outside skill discovery.
